# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro static output, TypeScript and small browser scripts. No UI framework or server runtime. The marketing site is separate from the Go CLI runtime.

## Users

Humans and AI-agent operators who want a local, readable knowledge base and an explicit setup workflow.

## Product Purpose

Help visitors understand KB and install its CLI and knowledge-base skill. Markdown is the source of truth. Search, read and revision-aware changes operate on a deliberately selected base.

## Capabilities and Constraints

CLI plus skill is the primary path. Installation does not establish an agent consultation policy. Preserve existing bases and configuration. MCP remains an optional independent interface. No accounts, telemetry, external runtime assets or invented usage/performance claims.

## Brand Commitments

Preserve the existing kb logo. Use the approved Midnight blue palette, restrained typography and real CLI/Markdown presentation. Public prose is English.

## Evidence on Hand

The repository README, quickstart, CLI guide, installation and agent setup documentation are canonical. Examples on the landing are explicitly illustrative, not captured user data.

## Accessibility & Inclusion

Responsive layout, semantic HTML, visible keyboard focus, keyboard-operable tabs, copy success/failure feedback and reduced-motion support.
