# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro static output, TypeScript and small browser scripts. No UI framework or server runtime. The marketing site is separate from the Go CLI runtime.

## Users

Humans and AI-agent operators who want a local, readable knowledge base and an explicit setup workflow.

## Product Purpose

Help visitors understand KB and choose an explicit agent setup workflow. Markdown is the source of truth. Search, read and revision-aware changes operate on a deliberately selected base.

## Capabilities and Constraints

CLI plus bundled skill is the primary setup path, with explicit root, project/global scope, agents and learning. Setup requires v1.1.0 or later; check installed version/help. Source builds remain optional and must run from the intended project, not the source checkout. Configured files are not native activation evidence. Preserve existing bases and configuration. MCP remains an optional independent interface. No accounts, telemetry, external runtime assets or invented usage/performance claims.

## Brand Commitments

Use the human-authorized blue-bird mascot from the shared brand source, the approved Midnight blue palette, restrained typography and real CLI/Markdown presentation. Public prose is English.

## Evidence on Hand

The repository README, quickstart, CLI guide, installation and agent setup documentation are canonical. Examples on the landing are explicitly illustrative, not captured user data.

## Accessibility & Inclusion

Responsive layout, semantic HTML, visible keyboard focus, keyboard-operable tabs, copy success/failure feedback and reduced-motion support.
